The examples run in your browser. You can play, pull, edit and save them without an account or a cloud GPU. A WebGL 2 browser is required.

Explore the glove and its input photographs or try the sloth's recorded motion.

Start with a capture

Keep the object still and move the camera around it in even light. Include the back and top. Use overlapping photos or a short orbit video; avoid blur, mirrors, transparent surfaces and changing the object's shape.

Review your capture to choose up to twelve views. Originals and your selection stay in this browser until you explicitly submit views to your own configured worker. Browser storage is not a backup; keep the original files.

Run Morphic on your computer

Download the Morphic source, extract it, and install Node.js 22.12 or later. In the extracted folder: 

npm ci
npm run examples:download
npm run dev

The example download is approximately 146 MB, fetched once and checked against recorded file hashes. The source archive contains no model weights, cloud credentials or personal captures.

Create using your own GPU

Reconstruction runs outside the browser. The current backend is Microsoft's TRELLIS, which requires Linux and an NVIDIA GPU with at least 16 GB of VRAM. Morphic's tested configuration is an A100 with 80 GB. AMD integrated graphics can display the studio but cannot run this CUDA reconstruction path. Other compatible GPUs have not been tested here.

  1. Install the official TRELLIS environment on your Linux GPU machine, following its upstream installation instructions. Use source revision 442aa1e1afb9014e80681d3bf604e8d728a86ee7 to reproduce this example.
  2. In that environment, run the included worker on one or more photographs. Set the paths for your machine; the output folder must be new. 
python scripts/reconstruct-baseline.py \
  --source /path/to/TRELLIS \
  --images /path/to/front.jpg /path/to/back.jpg \
  --output /path/to/new-object

The worker writes asset.glb and result.json. In the studio, choose an everyday object, open Save and open → Open 3D file, and select both files. Morphic verifies the result and prepares it for interaction. This is a technical installation, not a one-click GPU installer.

For a prepared Runpod worker under your own account, the source includes docs/GPU_SETUP.md and npm run studio:gpu -- --help. This connects the local studio through SSH. It does not rent hardware or stop billing; you control the worker and stop it after saving your outputs.

What to expect

The seven-photo glove run took about 126 seconds after the worker was installed: 97 seconds loading and preparing inputs, 6 seconds of inference and 23 seconds exporting. Initial installation and downloads take additional time. These are one run's measurements, not a speed guarantee.

Hidden surfaces are generated estimates. More views do not always improve them. Reconstructed objects use assigned simulation; photographs alone do not establish how an object bends. The sloth study separately fits a response to observed motion, with its limitations explained in the article.

Save something you can reopen

Save session keeps the appearance, simulation and interaction history together. Reopen it in the corresponding workspace and replay your actions. Export 3D shape saves a static GLB for other tools; it does not include the physical simulation. The sloth workspace also exports a video.
